# SafeKid

Parental-control mobile app for parents and children. One app, two roles:
parents control child devices remotely; children link their device to a parent
(parent approval required).

- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Decisions: [docs/decisions/](docs/decisions/)

## Repository layout

| Path              | What                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| `apps/backend`    | NestJS API (PostgreSQL via Prisma, Redis, WebSocket, FCM)                    |
| `apps/mobile`     | React Native + Expo app (dev builds) with the `device-control` native module |
| `packages/shared` | Shared TypeScript types and zod schemas                                      |
| `docs/`           | Architecture and ADRs                                                        |

## Prerequisites

- Node.js 22 (`.nvmrc`), pnpm 11 (`corepack enable`)
- Docker Desktop
- Android: Android Studio + SDK, JDK 17+, a physical device or emulator

## Setup

```bash
pnpm install
cp .env.example .env               # dev service ports/credentials
docker compose up -d               # Postgres on :5433, Redis on :6380
```

### Backend

```bash
cp apps/backend/.env.example apps/backend/.env
# replace JWT_ACCESS_SECRET and HASH_PEPPER: openssl rand -base64 48
pnpm --filter @safekid/shared build   # backend consumes the compiled shared package
pnpm --filter backend prisma:migrate  # apply migrations to the dev database
pnpm --filter backend dev             # http://localhost:3000/v1/health
pnpm --filter backend test            # unit + e2e (uses the safekid_test database)
```

In development OTP codes are printed to the backend log (`SMS_PROVIDER=console`)
and pushes are logged instead of sent (`PUSH_PROVIDER=console`).

### Mobile (Android dev build)

The app uses native modules, so it runs as a development build (not Expo Go).

```bash
pnpm --filter @safekid/shared build
cd apps/mobile
pnpm android        # prebuild + build + install the dev client on a device/emulator
# low on disk? build only for 64-bit phones:
# (cd android && ./gradlew assembleDebug -PreactNativeArchitectures=arm64-v8a)
pnpm start          # Metro for the installed dev client
```

On a physical phone, connect to the same Wi-Fi as your computer; the app talks to
`http://<computer IP>:3000` in development (override with `EXPO_PUBLIC_API_URL`,
see `apps/mobile/.env.example`). `android/` and `ios/` are generated by
`expo prebuild` and not committed.
